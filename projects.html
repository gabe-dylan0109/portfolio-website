Penetration Testing

Afriyie Bank — Vulnerable Web Application Lab

A deliberately vulnerable banking web application prototyped as a penetration testing target. Simulates real-world financial application attack surfaces including authentication flows, session management, transaction handling, and input validation weaknesses.

PythonFlaskSQLHTML/CSS/JSBurp Suite

Vulnerabilities Discovered

  • Reflected XSS in transaction history search field
  • Missing CSRF protection on fund transfer forms
  • Hardcoded cryptographic secrets enabling session hijacking
  • Misconfigured server environment exposing interactive debugger

Remediation Applied

  • Input sanitisation and output encoding for XSS prevention
  • Implementation of anti-CSRF tokens on all state-changing forms
  • Migration of hardcoded secrets to secure environment variables
  • Disabling of interactive debuggers for production environments
  • All findings documented with CVSS scoring and OWASP Top 10 mapping
DevSecOps

Image-to-PDF Converter — Secure App Prototyping Lab

A cross-platform image-to-PDF application built with Flutter/Dart and a Python prototype. The project served as a controlled lab for practising full-cycle application security auditing: build, test, break, fix, document.

Flutter/DartPythonADBAPK DecompilationCSP

Security Audit Findings

  • Temporary file disclosure — sensitive PDFs accessible via ADB
  • Client-side DoS vulnerability via unbounded file input
  • Missing Content Security Policy headers on web build
  • HTTPS certificate validation gaps in network requests

Mitigations Implemented

  • Secure temp-file handling with immediate cleanup after export
  • Input size limits and streaming processing for memory safety
  • CSP and HTTP security header hardening on web deployment
  • Reproducible lab steps documented for stakeholder review
