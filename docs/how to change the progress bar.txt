### 🛠️ How to Edit This Yourself in the Future

Editing this section is actually very straightforward. When you want to update your progress or add new courses in the future, follow these steps:

#### 1. How to Change the Progress Bar Percentage
1. Open up [index.html](cci:7://file:///c:/Users/afriy/Desktop/dyl/infosec/CV/dylan-portfolio_website_final_Claude%20edit/index.html:0:0-0:0) in your text editor (VS Code, Notepad, etc.).
2. Use `Ctrl + F` and search for the name of the course (e.g., `CompTIA Security+`).
3. Look 3 lines below the course description, and you will find a line that looks like this:
   ```html
   <div class="bar" style="width:15%; background: #ef4444;"></div>
   ```
4. Simply change the number inside the `width:15%;` to whatever you want! For example, changing it to `width:50%;` will fill the bar halfway. Once you are done with the course, change it to `width:100%;` to fill it completely.

#### 2. How to Add a Brand New Course Card
If you start a totally new course, you can easily add another card to the grid!
1. Scroll to the `<!-- CURRENTLY LEARNING -->` section in your [index.html](cci:7://file:///c:/Users/afriy/Desktop/dyl/infosec/CV/dylan-portfolio_website_final_Claude%20edit/index.html:0:0-0:0) file.
2. Highlight and block copy an **entire existing card**. An entire card block looks exactly like this, starting from `<div class="learn-card reveal">` and ending at its closing `</div>`:
   ```html
   <div class="learn-card reveal">
     <div class="learn-icon blue"><i class="fas fa-user-graduate"></i></div>
     <h4>Course Name Here</h4>
     <p>Description of what you are studying.</p>
     <div class="learn-progress">
       <div class="bar" style="width:10%;"></div>
     </div>
   </div>
   ```
3. Paste that copied block directly above the closing `</div>` of the `<div class="learning-grid">` section.
4. Update the text inside the `<h4>` tags (Title) and `<p>` tags (Description), and adjust the `width` percentage for your progress. You can also pick a different color icon by changing `blue` to `green` or `amber`!
